## 2. 「1日ずれ」から推測できること

削除によってスパイクが移動することから、以下が推測されます：

- DailyData には **2026-02-16 以降、連続した日付で同一の累積値が多数記録されている**
- 連続した日付では（cumulative が変わらないため）increment = 0
- しかし「ギャップ（記録なし日）の後の最初の記録日」だけスパイクが発生する
- 今日の削除はギャップを1日ずらしただけで、根本は何も変わっていない

**謎の核心**: なぜ `2026-02-16` と `2026-02-24` の両方でスパイクが発生するのか。
Apps Script のロジック（`prevCount` は data がある日のみ更新）通りなら、
2026-02-16 で prevCount = 累積値C に更新された後、2026-02-24 では diff = 0 になるはずです。
しかし実際は +234 になっており、この矛盾が未解決のまま残っています。
