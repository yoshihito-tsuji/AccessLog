# 三者協働開発ルール

セッション開始前のチェックリストやコミュニケーション原則をまとめています。

## 🤝 三者協働開発ルール

本プロジェクトは PoPuP 開発体制を踏襲し、**Yoshihitoさん（オーナー）**, **Codex（上流工程・設計）**, **Claude Code（実装担当）**の三者協働で進みます。

### セッション開始チェックリスト（必須順）
1. **README.md** – システム目的 / 最新状況を再確認
2. **@claude.md / @codex.md** – 各AIの役割とコミュニケーション形式を確認
3. **COLLABORATION.md** – 協働ルール、意思決定手順、ログ運用を把握
4. **最新ログ・成果物** – `tracker.log`, `tracker_error.log`, `downloads_*.csv` などを確認し現状を共有

### コミュニケーション原則
- すべて日本語で記述し、専門用語には補足を添える
- AIメッセージは `From: / To:` ヘッダー＋空行を必須とする
- Yoshihitoさんには必ず敬称を付け、意図が不明な場合は必ず確認する
- 重要な判断は README か `COLLABORATION.md` に記録し、経緯と理由を残す

詳細な運用手順・ログ様式・Git方針は `COLLABORATION.md` を参照してください。
